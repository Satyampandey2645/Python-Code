Manipulating Tuples (Python)

🔹 Why Tuples Cannot Be Modified
-> Tuples are immutable, meaning:
    * You cannot add, remove, or change elements after creation.

-> To modify a tuple:
    1. Convert tuple → list
    2. Perform changes
    3. Convert list → tuple

🔹 Modifying a Tuple (Using List Conversion)
    Steps:
    1. Convert tuple to list using list()
    2. Apply list methods (append, pop, indexing, etc.)
    3. Convert list back to tuple using tuple()

    Example:    
        countries = ("Spain", "Italy", "India", "England", "Germany")

        temp = list(countries)

        temp.append("Russia")     # Add item
        temp.pop(3)               # Remove item at index 3
        temp[2] = "Finland"       # Modify item

        countries = tuple(temp)
        print(countries)

    Output:
        ('Spain', 'Italy', 'Finland', 'Germany', 'Russia')

    ✅ Key Point for Interview:
        Tuples themselves cannot be changed, but we can modify them indirectly using lists.        

🔹 Concatenating Tuples
    * Tuples can be combined directly using the + operator.
    * No need to convert them into lists.

    Example:
        countries1 = ("Pakistan", "Afghanistan", "Bangladesh", "Sri Lanka")
        countries2 = ("Vietnam", "India", "China")

        southEastAsia = countries1 + countries2
        print(southEastAsia)

    Output:
        ('Pakistan', 'Afghanistan', 'Bangladesh', 'Sri Lanka', 'Vietnam', 'India', 'China')

🔹 Tuple Methods
    Since tuples are immutable, they have only two built-in methods:

1️⃣ count() Method
    Purpose:
        Returns the number of times a given element appears in the tuple.

    Syntax:
        tuple.count(element)

    Example:
        t = (0, 1, 2, 3, 2, 3, 1, 3, 2)
        res = t.count(3)
        print("Count of 3:", res)

    Output:
        Count of 3: 3

2️⃣ index() Method
    Purpose:
        Returns the index of the first occurrence of an element.

    Syntax:
        tuple.index(element)
        tuple.index(element, start, end)

    ⚠️ Important:
        Raises ValueError if the element is not found.

    Example:
        t = (0, 1, 2, 3, 2, 3, 1, 3, 2)
        res = t.index(3)
        print("First occurrence of 3 is:", res)

    Output:
        First occurrence of 3 is: 3

🔹 Interview One-Liners (Very Important ⭐):
    * Tuples are immutable, lists are mutable.
    * Tuples consume less memory than lists.
    * Tuples are faster than lists.
    * Only two tuple methods exist: count() and index()
    * Tuples are preferred when data should not change.
