🔹 Joining Sets in Python
    Sets in Python work similarly to mathematical sets. We can perform operations like union, intersection, difference, 
    and symmetric difference.

I. union() and update()

🔹 union()
    * Returns a new set
    * Contains all unique elements from both sets
    * Original sets remain unchanged

    Example:
        cities = {"Tokyo", "Madrid", "Berlin", "Delhi"}
        cities2 = {"Tokyo", "Seoul", "Kabul", "Madrid"}

        cities3 = cities.union(cities2)
        print(cities3)

    Output:
        {'Tokyo', 'Madrid', 'Kabul', 'Seoul', 'Berlin', 'Delhi'}

🔹 update()
    * Adds elements of another set into the existing set
    * Modifies the original set
    * Returns None

    Example:
        cities = {"Tokyo", "Madrid", "Berlin", "Delhi"}
        cities2 = {"Tokyo", "Seoul", "Kabul", "Madrid"}

        cities.update(cities2)
        print(cities)

    Output:
        {'Berlin', 'Madrid', 'Tokyo', 'Delhi', 'Kabul', 'Seoul'}

II. intersection() and intersection_update()

🔹 intersection()
    * Returns a new set
    * Contains common elements

    Example:
        cities = {"Tokyo", "Madrid", "Berlin", "Delhi"}
        cities2 = {"Tokyo", "Seoul", "Kabul", "Madrid"}

        cities3 = cities.intersection(cities2)
        print(cities3)

    Output:
        {'Madrid', 'Tokyo'}

🔹 intersection_update()
    * Updates the original set
    * Keeps only common elements

    Example:
        cities = {"Tokyo", "Madrid", "Berlin", "Delhi"}
        cities2 = {"Tokyo", "Seoul", "Kabul", "Madrid"}

        cities.intersection_update(cities2)
        print(cities)

    Output:
        {'Tokyo', 'Madrid'}

III. symmetric_difference() and symmetric_difference_update()

🔹 symmetric_difference()
    * Returns a new set
    * Contains elements not common to both sets

    Example:
        cities = {"Tokyo", "Madrid", "Berlin", "Delhi"}
        cities2 = {"Tokyo", "Seoul", "Kabul", "Madrid"}

        cities3 = cities.symmetric_difference(cities2)
        print(cities3)

    Output:
        {'Seoul', 'Kabul', 'Berlin', 'Delhi'}

🔹 symmetric_difference_update()
    * Updates original set
    * Removes common items

    Example:
        cities = {"Tokyo", "Madrid", "Berlin", "Delhi"}
        cities2 = {"Tokyo", "Seoul", "Kabul", "Madrid"}

        cities.symmetric_difference_update(cities2)
        print(cities)

    Output:
        {'Kabul', 'Delhi', 'Berlin', 'Seoul'}

IV. difference() and difference_update()

🔹 difference()
    * Returns elements present only in first set

    Example:
        cities = {"Tokyo", "Madrid", "Berlin", "Delhi"}
        cities2 = {"Seoul", "Kabul", "Delhi"}

        cities3 = cities.difference(cities2)
        print(cities3)

    Output:
        {'Tokyo', 'Madrid', 'Berlin'}

🔹 difference_update()
    * Removes elements found in another set

    Example:
        cities = {"Tokyo", "Madrid", "Berlin", "Delhi"}
        cities2 = {"Seoul", "Kabul", "Delhi"}

        cities.difference_update(cities2)
        print(cities)

    Output:
        {'Tokyo', 'Berlin', 'Madrid'}

🔹 Important Set Methods (Interview Focus)

🔸 isdisjoint()
    ✔ Returns True if no common elements

    Example:
        cities = {"Tokyo", "Madrid", "Berlin", "Delhi"}
        cities2 = {"Tokyo", "Seoul", "Kabul", "Madrid"}

        print(cities.isdisjoint(cities2))

    Output:
        False

🔸 issuperset()
    ✔ Checks if set contains all elements of another set

    Example:
        cities = {"Tokyo", "Madrid", "Berlin", "Delhi"}
        cities2 = {"Seoul", "Kabul"}

        print(cities.issuperset(cities2))

    Output:
        False

🔸 issubset()
    ✔ Checks if all elements of one set exist in another

    Example:
        cities = {"Tokyo", "Madrid", "Berlin", "Delhi"}
        cities2 = {"Delhi", "Madrid"}

        print(cities2.issubset(cities))

    Output:
        True

🔸 add()
    ✔ Adds one element

    Example:
        cities = {"Tokyo", "Madrid", "Berlin", "Delhi"}
        cities.add("Helsinki")
        print(cities)

🔸 update()
    ✔ Adds multiple elements

    Example:
        cities = {"Tokyo", "Madrid", "Berlin", "Delhi"}
        cities2 = {"Helsinki", "Warsaw", "Seoul"}

        cities.update(cities2)
        print(cities)

🔸 remove() vs discard()
    ✔ We can use remove() and discard() methods to remove items from sets.
    ✔ The main difference between remove and discard is that, if we try to delete an item which is not present in set, 
       then remove() raises an error, whereas discard() does not raise any error.

    Example:
        cities = {"Tokyo", "Madrid", "Berlin", "Delhi"}
        cities.remove("Tokyo")   # Error if not found
        cities.discard("Seoul")  # No error

| Method    | Error if item not found |
| --------- | ----------------------- |
| remove()  | ❌ Yes                  |
| discard() | ✅ No                   |

🔸 pop()
    ✔ Removes random element (because sets are unordered)

    Example:
        cities = {"Tokyo", "Madrid", "Berlin", "Delhi"}

        item = cities.pop()
        print(cities)
        print(item)

🔸 del
    ✔ Deletes the entire set

    Example:
        cities = {"Tokyo", "Madrid", "Berlin", "Delhi"}
        del cities

    Accessing after deletion → ❌ NameError

🔸 clear()
    ✔ Removes all elements but keeps the set

    Example:
        cities = {"Tokyo", "Madrid", "Berlin", "Delhi"}
        cities.clear()
        print(cities)

    Output:
        set()

🔥 Interview One-Line Summary:
    Python sets are unordered collections of unique elements that support mathematical operations like union, intersection, 
    and difference.
