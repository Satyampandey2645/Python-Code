🔹 String Slicing & Operations on String

🔹 Length of a String
   We can find the length of a string using the built-in len() function.

   Example:
        fruit = "Mango"
        leni = len(fruit)

        print("Mango is a", leni, "letter word.")

        Output:
            Mango is a 5 letter word.

🔹 String as an Array
   A string is a sequence (array) of characters, so we can access its elements using indexing.
    -> Index starts from 0
    -> Square brackets [ ] are used to access characters

   Example:
        pie = "ApplePie"

        print(pie[:5])
        print(pie[6])  # returns character at specified index

        Output:
            Apple
            i

🔹 String Slicing
   Slicing is used to extract a portion of a string by specifying a start and end index.

   Syntax:
    string[start : end]

   * Start index → inclusive
   * End index → exclusive

🔹 Slicing Examples:
        pie = "ApplePie"

        print(pie[:5])    # Slicing from start (0 to 4)
        print(pie[5:])    # Slicing till end (5 to length)
        print(pie[2:6])   # Slicing in between (2 to 5)
        print(pie[-8:])   # Slicing using negative index

        Output:
            Apple
            Pie
            pleP
            ApplePie

🔹 Negative Indexing (Concept):
   A   p   p   l   e   P   i   e
   0   1   2   3   4   5   6   7
   -8 -7  -6  -5  -4  -3  -2  -1

🔹 Looping Through a String
   Strings are iterable, so we can loop through them using a for loop.

   Example:
        alphabets = "ABCDE"

        for i in alphabets:
            print(i)

        Output:
            A
            B
            C
            D
            E

🔹 Important Points to Remember
   -> Strings are immutable
   -> Indexing starts from 0
   -> Slicing format: string[start : end]
   -> Start index is inclusive
   -> End index is exclusive
   -> Slicing does not modify the original string
   -> Negative indexing counts from the end
   -> If start > end, result is an empty string

🔹 Summary
   -> len() → finds string length
   -> Strings act like arrays
   -> Slicing extracts part of a string
   -> Strings can be looped using for
