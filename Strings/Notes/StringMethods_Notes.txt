🔹 String Methods in Python
   Python provides a rich set of built-in string methods to manipulate and modify strings.

⚠️ Strings are immutable, so these methods return a new string.

🔹 upper()
   Converts the string to uppercase.

   Example:
        str1 = "AbcDEfghIJ"
        print(str1.upper())

    Output:
        abcdefghij

🔹 lower()
   Converts the string to lowercase.

   Example: 
      str1 = "AbcDEfghIJ"
      print(str1.lower())

   Output:
      abcdefghij

🔹 strip()
   Removes leading and trailing whitespaces.

   Example:
      str2 = " Silver Spoon "
      print(str2.strip())

   Output:
      Silver Spoon

🔹 rstrip()
   Removes trailing characters.

   Example:
      str3 = "Hello !!!"
      print(str3.rstrip("!"))

   Output:
      Hello 

🔹 replace()
   Replaces all occurrences of a substring with another substring.

   Example:
      str2 = "Silver Spoon"
      print(str2.replace("Sp", "M"))

   Output:
      Silver Moon

🔹 split()
   Splits the string into a list based on a delimiter.

   Example:
      str2 = "Silver Spoon"
      print(str2.split(" "))

   Output:
      ['Silver', 'Spoon']

🔹 capitalize()
   Converts only the first character to uppercase and rest to lowercase.

   Example:
      str1 = "hello"
      print(str1.capitalize())

      str2 = "hello WorlD"
      print(str2.capitalize())

   Output:
      Hello
      Hello world

🔹 center()
   Centers the string with optional padding character.

   Example:
      str1 = "Welcome to the Console!!!"
      print(str1.center(50))

   Output:
              Welcome to the Console!!!         

   With padding character:
      print(str1.center(50, "."))

   Output:
      ............Welcome to the Console!!!.............

🔹 count()
   Returns the number of occurrences of a substring.

   Example:
      str2 = "Abracadabra"
      print(str2.count("a"))

   Output:
      4

🔹 endswith()
   Checks if the string ends with a given value.

   Example:
      str1 = "Welcome to the Console !!!"
      print(str1.endswith("!!!"))

   Output:
      True
 
   With range:
      print(str1.endswith("to", 4, 10))

   Output:
      True

🔹 find()
   Returns the index of first occurrence of substring.
   Returns -1 if not found.

   Example:
      str1 = "He's name is Dan. He is an honest man."
      print(str1.find("is"))

   Output:
      10

   If not found:
      print(str1.find("Daniel"))

   Output:
      -1

🔹 index()
   Same as find() but raises error if not found.

   Example:
      str1 = "He's name is Dan. Dan is an honest man."
      print(str1.index("Dan"))

   Output:
      13

   If not found:
      print(str1.index("Daniel"))

   Output:
      ValueError: substring not found

🔹 isalnum()
   Returns True if string contains only alphabets and digits.

   Example:
      str1 = "WelcomeToTheConsole"
      print(str1.isalnum())

   Output:
      True

🔹 isalpha()
   Returns True if string contains only alphabets.

   Example:
      str1 = "Welcome"
      print(str1.isalpha())

   Output:
      True

🔹 islower()
   Returns True if all characters are lowercase.

   Example:
      str1 = "hello world"
      print(str1.islower())

   Output:
      True

🔹 isprintable()
   Returns True if all characters are printable.

   Example:
      str1 = "We wish you a Merry Christmas"
      print(str1.isprintable())

   Output:
      True

🔹 isspace()
   Returns True if string contains only whitespaces.

   Example:
      str1 = "    "
      print(str1.isspace())

      str2 = "\t"
      print(str2.isspace())

   Output:
      True
      True

🔹 istitle()
   Returns True if first letter of each word is capitalized.

   Example:
      str1 = "World Health Organization"
      print(str1.istitle())

      str2 = "To kill a Mocking bird"
      print(str2.istitle())

   Output:
      True
      False

🔹 isupper()
   Returns True if all characters are uppercase.

   Example:
      str1 = "WORLD HEALTH ORGANIZATION"
      print(str1.isupper())

   Output:
      True

🔹 startswith()
   Checks if string starts with given value.

   Example:
      str1 = "Python is an Interpreted Language"
      print(str1.startswith("Python"))

   Output:
      True

🔹 swapcase()
   Converts uppercase to lowercase and vice versa.

   Example:
      str1 = "Python is a Interpreted Language"
      print(str1.swapcase())

   Output:
      pYTHON IS A iNTERPRETED lANGUAGE

🔹 title()
   Capitalizes the first letter of each word.

   Example:
      str1 = "His name is Dan. Dan is an honest man."
      print(str1.title())

   Output:
      His Name Is Dan. Dan Is An Honest Man. 

🔹 Key Points to Remember
   -> Strings are immutable
   -> All methods return new strings
   -> find() → returns -1
   -> index() → raises error
   -> Methods like isalpha() return Boolean
