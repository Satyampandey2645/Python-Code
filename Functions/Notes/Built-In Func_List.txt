----------------------------------------------- Python built-in functions -----------------------------------------------

| Alphabet | Built-in Function | Description                                            |
| -------- | ----------------- | ------------------------------------------------------ |
| A        | `abs()`           | Returns the absolute (positive) value of a number      |
|          | `aiter()`         | Returns an asynchronous iterator                       |
|          | `all()`           | Returns `True` if all elements in an iterable are true |
|          | `anext()`         | Returns next item from an async iterator               |
|          | `any()`           | Returns `True` if any element in an iterable is true   |
|          | `ascii()`         | Returns a printable representation of an object        |
| B        | `bin()`           | Converts a number to binary format                     |
|          | `bool()`          | Converts a value to Boolean (`True` or `False`)        |
|          | `breakpoint()`    | Starts the debugger                                    |
|          | `bytearray()`     | Returns a mutable byte array                           |
|          | `bytes()`         | Returns an immutable bytes object                      |
| C        | `callable()`      | Checks if an object can be called                      |
|          | `chr()`           | Converts ASCII value to character                      |
|          | `classmethod()`   | Converts a method into a class method                  |
|          | `compile()`       | Compiles source code into executable code              |
|          | `complex()`       | Creates a complex number                               |
| D        | `delattr()`       | Deletes an attribute from an object                    |
|          | `dict()`          | Creates a dictionary                                   |
|          | `dir()`           | Returns list of attributes of an object                |
|          | `divmod()`        | Returns quotient and remainder                         |
| E        | `enumerate()`     | Adds index to iterable                                 |
|          | `eval()`          | Executes expression as Python code                     |
|          | `exec()`          | Executes Python code dynamically                       |
| F        | `filter()`        | Filters elements based on condition                    |
|          | `float()`         | Converts value to float                                |
|          | `format()`        | Formats a value                                        |
|          | `frozenset()`     | Creates immutable set                                  |
| G        | `getattr()`       | Returns value of object attribute                      |
|          | `globals()`       | Returns global symbol table                            |
| H        | `hasattr()`       | Checks if object has attribute                         |
|          | `hash()`          | Returns hash value of object                           |
|          | `help()`          | Shows help documentation                               |
|          | `hex()`           | Converts number to hexadecimal                         |
| I        | `id()`            | Returns unique identity of object                      |
|          | `input()`         | Takes input from user                                  |
|          | `int()`           | Converts value to integer                              |
|          | `isinstance()`    | Checks object type                                     |
|          | `issubclass()`    | Checks class inheritance                               |
|          | `iter()`          | Returns iterator object                                |
| L        | `len()`           | Returns length of object                               |
|          | `list()`          | Creates a list                                         |
|          | `locals()`        | Returns local symbol table                             |
| M        | `map()`           | Applies function to iterable                           |
|          | `max()`           | Returns maximum value                                  |
|          | `memoryview()`    | Access memory of object                                |
|          | `min()`           | Returns minimum value                                  |
| N        | `next()`          | Returns next item from iterator                        |
| O        | `object()`        | Creates base object                                    |
|          | `oct()`           | Converts number to octal                               |
|          | `open()`          | Opens a file                                           |
|          | `ord()`           | Converts character to ASCII value                      |
| P        | `pow()`           | Returns power of a number                              |
|          | `print()`         | Prints output                                          |
|          | `property()`      | Defines property of class                              |
| R        | `range()`         | Generates sequence of numbers                          |
|          | `repr()`          | Returns string representation                          |
|          | `reversed()`      | Returns reversed iterator                              |
|          | `round()`         | Rounds a number                                        |
| S        | `set()`           | Creates a set                                          |
|          | `setattr()`       | Sets attribute value                                   |
|          | `slice()`         | Returns slice object                                   |
|          | `sorted()`        | Returns sorted list                                    |
|          | `staticmethod()`  | Defines static method                                  |
|          | `str()`           | Converts value to string                               |
|          | `sum()`           | Returns sum of elements                                |
|          | `super()`         | Access parent class                                    |
| T        | `tuple()`         | Creates a tuple                                        |
|          | `type()`          | Returns type of object                                 |
| V        | `vars()`          | Returns object’s attributes                            |
| Z        | `zip()`           | Combines iterables                                     |
| _        | `__import__()`    | Imports a module dynamically                           |
