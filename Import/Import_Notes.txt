🔹 Importing in Python (Interview Notes)

    🔸 What is Importing?
        Importing in Python is the process of loading code (functions, variables, classes) from a module into the current 
        program so that it can be reused.

    A module is simply a Python file (.py) containing Python code.

1️⃣ Basic import Statement

    🔸 Syntax:
        import module_name

    🔸 Example:
        import math

        result = math.sqrt(9)
        print(result)   # 3.0

    Explanation:
        -> The entire module is imported
        -> Members are accessed using dot notation (module.function)

    ✅ Best for clarity
    ✅ Avoids name conflicts

2️⃣ from Keyword (Import Specific Items)

    🔸 Syntax:
        from module_name import name

    🔸 Example:
        from math import sqrt

        print(sqrt(9))  # 3.0

    🔸 Import multiple items:
        from math import sqrt, pi

        print(sqrt(9))  # 3.0
        print(pi)       # 3.141592653589793

    Explanation:
        -> Only selected items are imported
        -> Dot notation is not required
        ⚠ Risk of name conflicts if overused

3️⃣ Import Everything (*) ❌ (Not Recommended)

    🔸 Syntax:
        from module_name import *

    🔸 Example:
        from math import *

        print(sqrt(9))  # 3.0
        print(pi)       # 3.141592653589793

    🔸 Why NOT recommended?
        -> Pollutes namespace
        -> Hard to track where names come from
        -> Can override existing variables
    
    📌 Interview tip: Avoid import * in real projects

4️⃣ as Keyword (Alias)
    Used to rename a module or function.

    🔸 Example (Module alias):
        import math as m

        print(m.sqrt(9))  # 3.0
        print(m.pi)       # 3.141592653589793

    🔸 Example (Function alias):
        from math import sqrt as s

        print(s(16))  # 4.0

    🔸 Use cases:
        -> Shorter names
        -> Avoid naming conflicts
        -> Improves readability

5️⃣ dir() Function
    
    🔸 Purpose:
        Used to list all attributes (functions, variables, constants) inside a module.

    🔸 Example:
        import math
        print(dir(math))

    🔸 Output includes:
        -> Functions like sqrt, sin, cos
        -> Constants like pi, e

    📌 Useful for exploration & debugging

6️⃣ How Python Finds a Module (Important for Interviews)

    🔸 When you write:
        import math

    🔸 Python searches in this order:
        1. Current directory
        2. Built-in modules
        3. Directories in sys.path

    🔸 You can check it using:
        import sys
        print(sys.path)

7️⃣ Common Interview Questions

    Q1. What happens when a module is imported?
    👉 Python executes the module once and stores it in memory (sys.modules).

    Q2. Is importing expensive?
    👉 No. A module is loaded only once, even if imported multiple times.

    Q3. Difference between import math and from math import sqrt?   

        | Feature        | import math | from math import sqrt |
        | -------------- | ----------- | --------------------- |
        | Namespace      | math.sqrt   | sqrt                  |
        | Readability    | High        | Medium                |
        | Name conflicts | Low         | Possible              |


8️⃣ Best Practices ✅
    -> Prefer import module
    -> Use from module import specific_name when needed
    -> Avoid import *
    -> Use aliases carefully
    -> Keep imports at the top of the file

📝 One-Line Interview Answer 🎯
    Importing in Python allows reuse of code from modules using import, from, and as, and Python loads each module only 
    once during execution.
