🔹 Enumerate Function in Python
    The enumerate() function is a built-in Python function that allows you to loop over a sequence while keeping track of 
    both the index and the value at the same time.

    Instead of manually maintaining a counter, enumerate() does this automatically.

🔹 Why use enumerate()?

    🔸 Without enumerate():

        fruits = ['apple', 'banana', 'mango']
        index = 0

        for fruit in fruits:
            print(index, fruit)
            index += 1   

    🔸 With enumerate():

        fruits = ['apple', 'banana', 'mango']

        for index, fruit in enumerate(fruits):
            print(index, fruit)

    ✔ Cleaner
    ✔ More readable
    ✔ Less error-prone

🔹 Basic Example:

        fruits = ['apple', 'banana', 'mango']

        for index, fruit in enumerate(fruits):
            print(index, fruit)

    Output:
        0 apple
        1 banana
        2 mango

🔹 How enumerate() Works Internally:
    The enumerate() function returns tuples in the form:
        (index, value)

    🔸 Proof that it returns a tuple:

        fruits = ["apple", "banana", "mango"]

        for v in enumerate(fruits):
            print(v)

        print(type(v))

    Output:
        (0, 'apple')
        (1, 'banana')
        (2, 'mango')
        <class 'tuple'>

🔹 Changing the Starting Index:
    By default, indexing starts from 0, but you can change it using the start parameter.

    Example:
        fruits = ['apple', 'banana', 'mango']

        for index, fruit in enumerate(fruits, start=1):
            print(index, fruit)

    Output:
        1 apple
        2 banana
        3 mango

🔹 Common Practical Example:
        Printing serial numbers:
        fruits = ['apple', 'banana', 'mango']

        for index, fruit in enumerate(fruits):
            print(f"{index + 1}: {fruit}")

    Output:
        1: apple
        2: banana
        3: mango

🔹 Using enumerate() with Other Data Types:

    🔸 With Tuple:
        colors = ('red', 'green', 'blue')

        for index, color in enumerate(colors):
            print(index, color)

    Output:
        0 red
        1 green
        2 blue

    🔸 With String:
        s = "hello"

        for index, ch in enumerate(s):
            print(index, ch)

    Output:
        0 h
        1 e
        2 l
        3 l
        4 o

🔹 Syntax Summary:
        enumerate(iterable, start=0)

    * iterable → list, tuple, string, etc.
    * start → optional starting index

🔹 When to Use enumerate() ✔️
    ✅ When you need:
        * Index + value together
        * Clean and readable loops
        * Avoid manual counters

    ❌ Avoid:
        * When index is not needed

📝 Interview One-Line Answer 💡
    The enumerate() function in Python returns an iterator of tuples containing index and value, allowing us to loop 
    through a sequence while tracking positions efficiently.
