📘 Python Dictionaries
    A dictionary is an ordered collection of data items (from Python 3.7+).
    It stores data in key–value pairs.

    * Written using curly braces {}
    * Keys are unique
    * Values can be of any data type
    * Dictionaries are mutable (can be changed)

🔹 Creating a Dictionary:

    Example:
        info = {'name': 'Karan', 'age': 19, 'eligible': True}
        print(info)

    Output:
        {'name': 'Karan', 'age': 19, 'eligible': True}   

🔹 Accessing Dictionary Items:

I. Accessing Single Values
    We can access values using:
    1. Square brackets [key]
    2. get() method

    Example:
        info = {'name': 'Karan', 'age': 19, 'eligible': True}

        print(info['name'])
        print(info.get('eligible'))

    Output:
        Karan
        True

    ⚠️ Important Difference
        * info['key'] → ❌ Error if key not found
        * info.get('key') → ✅ Returns None if key not found      

II. Accessing All Values
    Use the values() method to get all values.

    Example:
        info = {'name': 'Karan', 'age': 19, 'eligible': True}

        print(info.values())

    Output:
        dict_values(['Karan', 19, True])  

III. Accessing All Keys
    Use the keys() method to get all keys.

    Example:
        info = {'name': 'Karan', 'age': 19, 'eligible': True}

        print(info.keys())

    Output:
        dict_keys(['name', 'age', 'eligible'])     

IV. Accessing Key–Value Pairs
    Use the items() method to get key–value pairs as tuples.

    Example:
        info = {'name': 'Karan', 'age': 19, 'eligible': True}

        print(info.items())

    Output:
        dict_items([('name', 'Karan'), ('age', 19), ('eligible', True)])                    

🔥 Interview One-Line Summaries:
    * Dictionary → Collection of key-value pairs
    * Keys → Unique & immutable
    * Values → Can be of any data type
    * get() → Safe way to access values
    * items() → Returns key-value pairs as tuples
